Garima weds Ankush: wedding website
=====================================

Upload this whole folder. index.html is the home page.

EASIEST: Netlify Drop (free, about 1 minute, no coding)
  1. Unzip this file.
  2. Go to https://app.netlify.com/drop
  3. Drag the unzipped "garima-ankush-wedding" folder onto the page.
  4. You get a link like https://something.netlify.app
     Rename it under Site settings > Change site name, e.g. garima-weds-ankush

OTHER OPTIONS
  Vercel:        vercel.com > Add New > Project > drag this folder in
  GitHub Pages:  push the folder to a repo > Settings > Pages > deploy from main
  Cloudflare:    pages.cloudflare.com > Create > Upload assets > drop this folder

WHATSAPP PREVIEW
  og-image.jpg is the preview card. Some apps need the full address:
  after deploying, change og-image.jpg on line 13 of index.html to
  https://YOUR-SITE.netlify.app/og-image.jpg

WHAT'S INSIDE
  index.html      the site (fonts built in)
  img/            photos and paintings
  js/             smooth scroll + map (no internet services needed for these)
  og-image.jpg    WhatsApp/Instagram link preview
  favicon.png     browser tab icon
